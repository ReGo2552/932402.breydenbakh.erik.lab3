# ЛР№3. Вёрстка макета с помощью Flexbox и Grid

Группа 932402, Брейденбах Эрик.

Вариант **2 — «Путешественник»** (навыки + прогресс-дашборд).

## Задание

Дополняет страницу «О себе» из ЛР№1/ЛР№2:

- Flexbox: навигационное меню (уже было в ЛР№2, делаем адаптивным) + карточки «Навыки» (3–4 шт., `flex-direction: column` внутри, `flex-wrap: wrap` в ряду), с прогресс-баром и `<dl>` «Навык / Уровень» в каждой.
- Grid: дашборд «Статистика прогресса» — 3 блока («Страны», «Города», «Фото»), `3×1` на десктопе / `1×3` на мобильном.
- Медиа-запросы под планшет и мобильный, без горизонтальной прокрутки.
- Контрастность не менее 4.5:1 (включая прогресс-бары), семантичные теги для карточек.
