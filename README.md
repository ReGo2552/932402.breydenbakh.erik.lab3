# ЛР№3. Вёрстка макета с помощью Flexbox и Grid

Группа 932402, Брейденбах Эрик.

Вариант **2 - «Путешественник»** (навыки + прогресс-дашборд).

Та же страница «О себе», что и в ЛР№1/ЛР№2 (`index.html`, `style/style.css` перенесены из ЛР№2 как стартовая точка), дополненная Flexbox- и Grid-раскладками.

## Что реализовано

**Flexbox:**

- Навигационное меню - `display: flex; flex-wrap: wrap`, на узких экранах ссылки переносятся, а не сжимаются.
- Карточки «Навыки» (`.skills-row` / `.skill-card`, 4 шт.) - ряд карточек на `flex-wrap: wrap`, внутри каждой `flex-direction: column`; в каждой карточке - `<dl>`/`dt`/`dd` для пары «Навык / Уровень» и прогресс-бар (`<div>` с `width` в %, оранжевая заливка на тёмно-сером фоне, `role="progressbar"` + ARIA-атрибуты).

**Grid:**

- Дашборд «Статистика прогресса» (`.progress-dashboard`) - 3 блока («Страны», «Города», «Фото»), `grid-template-columns: repeat(3, 1fr)`.

**Адаптивность (mobile-first, брейкпоинты 480/600/900px):**

- Карточки навыков: 1 колонка (моб.) → 2 (планшет, `min-width: 600px`) → 4 (десктоп, `min-width: 900px`).
- Grid-дашборд: 1 колонка на мобильном → 3 колонки от планшета (`min-width: 600px`).
- Хедер переключается в столбик на самых узких экранах (`≤480px`).
- Колонки текста в «Проектах» (из ЛР№2) на мобильном возвращаются в 1 колонку - читать 2 колонки на телефоне неудобно.
- `box-sizing: border-box` глобально + `%`/`fr`-единицы - горизонтальной прокрутки нет ни на одном брейкпоинте.

**Семантика:** `<article>` для карточек навыков и блоков статистики, `<section>` для дашборда.

**Контрастность** ≥4.5:1 сохранена и для новых элементов (например, цифры в `.stat-number` - ~7.7:1 на бежевом фоне).

## Визуальные улучшения (сверх минимума задания)

Сделаны отдельной веткой `style-improvements` (потом смёржена в `main`), маленькими коммитами:

- UX липкой навигации: `scroll-behavior: smooth` + `scroll-margin-top`, чтобы шапка не перекрывала заголовок секции при переходе по якорю.
- Тени и hover-подъём на карточках навыков и блоках статистики (`box-shadow`, `transform: translateY`).
- `text-shadow` на заголовке шапки, градиентный фон шапки вместо плоской заливки.
- Асимметричные радиусы скругления (`border-radius` с 4 разными значениями) на `<aside>` - вид открытки, с пунктирной рамкой и градиентом.
- Favicon (SVG data URI) и `<meta name="theme-color">`.
- Системный стек шрифтов вместо `Arial, Verdana` (без внешних зависимостей).
- Акцентная полоска и типографика лейблов в дашборде статистики.
- Кастомные CSS-счётчики (`counter()`) вместо стандартных цифр в «Проектах» - вид карточек-маршрутов, без потери семантики `<ol>`.
- Мягкое свечение при фокусе на полях формы вместо жёсткого `outline`.

Все правки перепроверены на контраст (≥4.5:1) отдельно от базовой реализации.

Открыть `index.html` в браузере. Адаптивность удобно проверять через DevTools → Toggle device toolbar, на ширинах около 480/600/900px (это и есть брейкпоинты).
